# Data and code use notice

The author-generated analysis scripts, benchmark organization, scoring records, and derived tables in this repository are supplied for scientific inspection and reproduction.

The source-qualified thermal-event reference summarizes facts reported in the cited scientific literature. It does not redistribute article full text. Bibliographic identifiers and source locators are provided so users can consult the original publications and their applicable terms.

The scored model tables contain structured fields derived from user-initiated model outputs. Raw provider responses, provider response identifiers, private reasoning traces, session metadata, and credentials are excluded. Users remain responsible for compliance with applicable provider terms when reusing model-derived records or independently repeating model collection.

No public software or data license has been selected in this release candidate. Add the author-approved license before publication; do not infer permission beyond applicable law and the terms attached to cited third-party sources.
